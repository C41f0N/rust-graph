# Rust Graph

## About
A Logseq like general purpose knowledge representation software, without the representational limitations of Logseq

## Current Ideas
  - Each node can carry files, images, and display assets (file or image that is displayed in the node's place in the graph)
  - Recursive graphs, a node can house another graph within it (handle using same named folders as node's md file)
  - Each link has many types, directed, undirected.
  - A single click solution to unwrap recursive graphs, and to create them based on the directed edges.
  - A way to add symlink type arrangement for nodes.
